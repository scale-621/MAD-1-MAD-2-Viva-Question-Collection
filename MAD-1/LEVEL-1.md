# MAD-1 - Level 1 Viva Questions

## Project introduction and demonstration

1. Introduce yourself. *(Asked 21 times)*
2. What did you understand from the problem statement? *(Asked 11 times)*
3. What is your project, and how did you approach the problem statement? *(Asked 16 times)*
4. Demonstrate the complete application and all core functionalities. *(Asked 266 times)*
5. Explain the end-to-end flow of the application. *(Asked 28 times)*
6. Explain the project directory structure and how the files are connected. *(Asked 19 times)*
7. Which frameworks and libraries did you use in the project? *(Asked 13 times)*
8. What database did you use, and why did you choose it? *(Asked 18 times)*
9. Explain the database tables, their columns, and the relationships between them. *(Asked 126 times)*
10. Show the ER diagram and explain the database schema. *(Asked 41 times)*
11. Explain any one route/controller and its complete execution flow. *(Asked 27 times)*
12. Show how the frontend, backend, and database communicate. *(Asked 14 times)*
13. Show the CRUD operations implemented in your project. *(Asked 34 times)*
14. What additional features did you implement beyond the core requirements? *(Asked 9 times)*
15. What challenges did you face while building the project? *(Asked 7 times)*
16. What did you learn from this project? *(Asked 6 times)*
17. What would you improve or add if you had more time? *(Asked 8 times)*
18. Rate your application and justify the rating. *(Asked 7 times)*

## Core web and database questions

19. What is Flask, and why did you use it? *(Asked 84 times)*
20. What is MVC? Show the Model, View, and Controller in your project. *(Asked 110 times)*
21. What is ORM, which ORM did you use, and where is it used in your project? *(Asked 123 times)*
22. What is a primary key, what is a foreign key, and how are they different? *(Asked 17 times)*
23. What is the difference between a primary key and a unique key? *(Asked 8 times)*
24. Explain one-to-one, one-to-many, and many-to-many relationships using your models. *(Asked 26 times)*
25. What is the difference between GET and POST, and when did you use each? *(Asked 43 times)*
26. Can data be sent through a GET request? If yes, how? *(Asked 12 times)*
27. What is authentication, what is authorization, and how are they different? *(Asked 73 times)*
28. How is the admin identified, and how are different user roles separated? *(Asked 12 times)*
29. What is Jinja2, and where did you use it? *(Asked 110 times)*
30. What is template inheritance? Show `extends` and `block` in your templates. *(Asked 60 times)*
31. What is Bootstrap, why did you use it, and how did you include it? *(Asked 35 times)*
32. What is the difference between frontend validation and backend validation? Which is more important? *(Asked 14 times)*
33. What is a session, what is a cookie, and where is each stored? *(Asked 16 times)*
34. What is Git, what is a version-control system, and is Git centralized or distributed? *(Asked 85 times)*

## Project-specific flow questions

35. Explain the complete `/login` route for both GET and POST requests. *(Asked 5 times)*
36. How is a parking spot selected and assigned to a user? *(Asked 2 times)*
37. How is parking cost calculated when a user releases a spot? *(Asked 2 times)*
38. How did you implement search, filtering, and case-insensitive matching? *(Asked 18 times)*
39. How did you prevent duplicate usernames or other duplicate records? *(Asked 8 times)*
40. How did you prevent overbooking or double-booking? *(Asked 5 times)*
41. How do you validate that a date or slot is not in the past? *(Asked 4 times)*
42. How does rescheduling free the old slot and reserve the new one consistently? *(Asked 2 times)*

44. Why is treatment/history data stored separately, and how is it fetched using a join? *(Asked 2 times)*
